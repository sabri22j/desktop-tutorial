# Voix humaines enregistrées

L'application lit **en priorité** un enregistrement humain s'il existe, sinon elle utilise la voix de synthèse de l'appareil.

1. Ouvrir `SCRIPT.md` : chaque leçon y figure avec le **nom de fichier exact** attendu.
2. Enregistrer chaque leçon (téléphone ou micro, pièce calme), en français naturel, à rythme posé.
3. Exporter en **MP3** (mono, ~96 kbit/s) ou **M4A**, et nommer le fichier `<chapitre>-<numéro de leçon>.mp3` (exemple : `c0-islam-0.mp3`).
4. Déposer les fichiers dans ce dossier `audio/`. Aucun code à modifier.

Règles importantes : n'utiliser que des voix dont vous avez les droits (vous-même, une personne qui vous autorise, ou une licence claire). Pour la récitation du Coran, demander l'autorisation du récitant ou utiliser une source libre de droits.
