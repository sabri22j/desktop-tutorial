# Voix de l'espace enfants

Fichiers `<thème>-c<0-2>.mp3` (leçons), `<thème>-q<0-2>.mp3` (questions) et `fx-*.mp3` (réactions), lus par Sirâj. Voix de synthèse (Piper, rendue plus aiguë) ; remplaçables par de vraies voix du même nom. Si un fichier manque, l'application lit le texte avec la voix de l'appareil.
